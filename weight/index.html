Log once per day, update anytime ▼
Logging today's weight switches the button to Update instead of Save, so entering a new number always edits today's single entry rather than creating a duplicate. You can update it as many times as you want during the day — only the latest value is kept.
Switch between lb and kg anytime ▼
Your unit choice (lb or kg) is shared with the Settings page, and every entry is stored normalized in kilograms internally. Switching units only changes how numbers are displayed — it never changes the underlying data or any entry you've already logged.
Log at the same time of day for a trend that means something ▼
Body weight can swing a few pounds or kilograms in a single day from food, water, and hydration alone — not just fat loss or gain. Logging at roughly the same time each day (first thing in the morning is typical) makes the Weight Over Time chart's trend far more meaningful than any single day's number.
