Workout Planner

Create workout routines, plan exercises, and follow personalized fitness programs.

Each program can have up to 7 days ▼
A program can hold up to 7 days, and every day needs at least one exercise before you can save. A program always keeps at least one day — once you're down to the last one, its Remove option disappears.
Your exercise library is shared across all programs ▼
Exercises you create are saved to a shared Exercise Library you can search and reuse in any program, not just the one you built it in. Adding one to a day copies its current sets, reps, and notes at that moment — later edits to the library update future additions, but won't retroactively change copies already placed in other programs' days.
Reorder exercises within a day anytime ▼
Use the ↑/↓ arrows next to each exercise to reorder it within a day. The library itself — creating, editing, or deleting exercises — can also be managed on its own via the Exercise Library button, independent of any specific program.
