Keeping Score - How It Works

To use the free scorekeeper, first add players using the form above. Then select a player to adjust their score using the controls. Players will automatically be ranked from highest to lowest score. You can reset all scores or delete all players using the buttons provided. All data is stored locally in your browser and will persist across sessions until cleared.
